# sungho-dashboard-data

Public, machine-readable summary data for the **SungHo Dashboard** Android widget.

- App endpoint: `latest.json`
- This repository is intentionally public so the Android app can read it without a GitHub token.
- Store **summary-only dashboard data** here.
- Do **not** store Gmail message bodies, email addresses, passwords/tokens, account balances, transaction histories, uploaded files, or other personal/private data.
- The private analysis engine source remains in a separate private repository.
